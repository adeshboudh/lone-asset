# First-person arms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the DJMaesen "fps arms" model in first person, posed every frame from the M4 pack rig that every weapon already animates, and take the body cut-outs out of the first-person view.

**Architecture:** A pure `FpsArmsRules` class does the frame maths (bone frame from a direction and a sideways axis, retarget of one bone). An `FpsArms` node, added by `Weapon._build_viewmodel` under the pack's `Skeleton3D`, owns the arms model and re-poses its skeleton after the pack skeleton updates. Tunables in `data/characters/fps_arms.tres`.

**Tech Stack:** Godot 4.7.2, typed GDScript, gdUnit4.

**Spec:** `docs/superpowers/specs/2026-11-15-fps-arms-design.md`

## Global Constraints

- Model `content/characters/fps_arms/fps_arms.glb`, "fps arms" by DJMaesen, CC-BY-4.0, https://skfb.ly/6R6yX, authored in centimetres (scale 0.01).
- Tunables in `data/**/*.tres`; logic in `*_rules.gd` with unit tests; scenario tests for scene behaviour.
- Arms on the default render layer, no shadow casting. The body stays hidden from the first-person camera and casts the shadow.
- Commit on `feat/m4a1-custom`, files staged explicitly; `tools/ci/run_tests.sh` and `reuse lint` pass.

## Review Focus

- Mirrored hands: the left hand must curl toward its palm exactly like the right (the earlier attempt broke here). Unit test with a mirrored pose.
- One-handed weapons (pistol, knife): the pack collapses its left arm (pose scale 0.001); the new left arm must vanish, not stretch.
- Weapon switch: each weapon has its own viewmodel and pack rig; arms must exist on all three and follow the current one.
- Reload: the left hand leaves the gun; the arms must follow the pack's wrist (within 1 cm) throughout the clip.
- The pack hand is about 1.2 times bigger than the new hand: fingers must still meet the grip (`hand_scale` tunable).

### Task 1: Retarget maths

**Files:** Create `game/player/fps_arms_rules.gd`; Test `tests/unit/test_fps_arms_rules.gd`

**Interfaces (produces):**
- `static func bone_frame(direction: Vector3, sideways: Vector3) -> Basis`: x = direction, z = sideways made perpendicular, y = z × x.
- `static func retarget(source_frame_pose: Basis, target_frame_rest: Basis, target_rest: Basis) -> Basis`: global basis for the target bone so that its frame matches the source frame (`source_frame_pose * target_frame_rest.inverse() * target_rest`).
- `const BONE_MAP: Dictionary` new-arm prefix to pack name per joint (`arm`→`Arm`, `elbow`→`ForeArm`, `wrist`→`Hand`, `thumb1..3`→`HandThumb1..3`, `point`→`Index`, `middle`, `ring`, `pink`→`Pinky`), `static func pack_bone(arms_bone: String) -> String` ("L_point2_09" → "LeftHandIndex2", "" for tips and the root).

- [ ] Tests: `bone_frame` is orthonormal with x along the direction; `retarget` of an unchanged pose returns the rest; for a mirrored pair (left frame = right frame mirrored in x) a curl about the source's own z gives a target fingertip moving toward the palm on both sides; `pack_bone` maps every non-tip arms bone and returns "" for `_rootJoint` and `*4_*`.
- [ ] Implement, run `tools/ci/run_tests.sh res://tests/unit/test_fps_arms_rules.gd`, PASS, commit.

### Task 2: The FpsArms node

**Files:** Create `game/player/fps_arms.gd`, `game/player/fps_arms_settings.gd`, `data/characters/fps_arms.tres`; Modify `game/weapons/weapon.gd` (`_build_viewmodel`); Test `tests/scenarios/test_fps_arms.gd`; Modify `content/LICENSES.md`.

**Interfaces:**
- `FpsArmsSettings extends Resource`: `model_scale := 0.01`, `hand_scale := 1.15`.
- `FpsArms extends Node3D`: `static func attach(viewmodel: Node3D, settings: FpsArmsSettings) -> FpsArms` (null when the viewmodel has no skeleton with a `RightHand` bone); `var skeleton: Skeleton3D` (the arms'); `func pose_from_pack() -> void`, called on the pack skeleton's `skeleton_updated`.
- Per mapped bone, parent first: frame from the direction to its first child and the hand's index1→pinky1 axis carried in the bone's rest frame; then each shoulder is moved so the wrist lands on the pack wrist; the wrist pose scale is `hand_scale`; a pack arm with pose scale below 0.01 gives its new arm scale 0.001.

- [ ] Tests (scenario, player scene on a floor): with each of the three weapons, the arms model exists under the viewmodel, is visible, layer 1, no shadow; each shown wrist within 1 cm of the pack wrist; left arm scale below 0.01 on pistol and knife; during the rifle's reload clip at 3 sampled times the left wrist stays within 1 cm; the left index fingertip lies on the palm side of the left hand (dot with palm normal > 0) and likewise for the right.
- [ ] Implement, run the scenario, PASS. Visual check with the screenshot script (first person, side). Commit with the model, its import files and the credit row.
